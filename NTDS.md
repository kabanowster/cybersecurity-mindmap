NT Directory Services

Local AD database storing credentials on [[Domain Controller]]s

`%SystemRoot%\NTDS\ntds.dit`
.dit = directory information tree

- User accounts (username & password hash)
- Group accounts
- Computer accounts
- Group policy objects
